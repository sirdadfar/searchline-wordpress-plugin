# Searchline برای WooCommerce

یک افزونه حرفه‌ای و ماژولار برای اتصال سرویس استعلام Searchline به WooCommerce.

ویژگی‌ها:
- سازگاری با HPOS
- پشتیبانی از Checkout کلاسیک و Checkout Block
- Registry برای استعلام‌ها
- اعتبارسنجی کد ملی، موبایل، کارت، شبا، کدپستی و IMEI
- نرمال‌سازی ارقام فارسی و عربی
- مدیریت استعلام در سفارش
- Callback و ابزارهای حریم خصوصی
- قابل توسعه با Hookهای وردپرس

مالک فروشگاه مسئول دریافت رضایت کاربر و رعایت قوانین مربوط به پردازش اطلاعات است.
