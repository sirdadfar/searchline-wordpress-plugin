Searchline identity and information inquiries for WooCommerce.

== External services ==
Depending on enabled inquiries, selected checkout/order data is sent to the Searchline service configured by the administrator when an enabled inquiry is triggered. Data can include national ID, birth date, mobile, postal code, card/Sheba, IMEI, IP/location and related values.

== Privacy ==
Sensitive data should be stored only when required. The merchant is responsible for consent, lawful processing and retention.
